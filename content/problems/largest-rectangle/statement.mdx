## 题目描述

有 $n$ 根紧挨着竖立的柱子，从左到右编号 $1 \dots n$。每根柱子宽度都是 $1$，第 $i$
根的高度是 $h_i$。

请在这片柱状图里找出一个面积最大的矩形——它必须由**连续若干根**柱子构成，高度取
这些柱子里最矮的那根。输出这个最大面积。

## 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $h_1, h_2, \dots, h_n$。

## 输出格式

一行一个整数，表示最大矩形面积。

## 数据范围

对于全部数据，保证 $1 \le n \le 10^6$，$0 \le h_i \le 10^9$。

| 子任务 | 分值 | 限制 |
| --- | --- | --- |
| 1 | 30 | $n \le 10^3$ |
| 2 | 30 | $n \le 10^5$ |
| 3 | 40 | 无特殊限制 |

<Callout kind="tip" title="解题提示">

换个角度枚举：让每根柱子分别当一次矩形的高。对第 $i$ 根，矩形能向左右扩张到
**第一根比它矮的柱子**为止，宽度就定下来了。

于是问题变成「对每个位置求左右两侧第一个更矮的位置」，这正是单调栈的活。维护一个
高度递增的栈，新柱子比栈顶矮时就不断弹栈——被弹出的那根，右边界恰好是当前位置，
左边界是弹出后的新栈顶。整个过程每根柱子进出栈各一次，复杂度 $O(n)$。

</Callout>

## 参考实现片段

```cpp title="monotonic-stack.cpp" showLineNumbers
h[n] = -1;              // 哨兵，保证结束时把栈清空
stack<int> st;
long long best = 0;

for (int i = 0; i <= n; ++i) {
    while (!st.empty() && h[st.top()] >= h[i]) {
        int top = st.top();
        st.pop();
        int left = st.empty() ? -1 : st.top();
        best = max(best, (long long)h[top] * (i - left - 1));
    }
    st.push(i);
}
```

<Callout kind="warning">

面积最大可达 $10^{15}$ 量级，必须用 64 位整数。

$n$ 到 $10^6$ 时 `cin` 的默认同步会成为瓶颈，记得关掉同步或改用更快的读入。

</Callout>
