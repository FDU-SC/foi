## 题目描述

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，你需要依次处理 $q$ 个操作。
操作有两种：

- `1 x v` —— 把 $a_x$ 增加 $v$（$v$ 可能是负数）
- `2 l r` —— 查询 $a_l + a_{l+1} + \dots + a_r$ 的值

## 输入格式

第一行两个整数 $n$ 和 $q$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

接下来 $q$ 行，每行是一个操作，格式如上。

## 输出格式

对每个 `2` 操作输出一行，表示该区间的和。

<Sample
  n={1}
  input={`5 5
1 2 3 4 5
2 1 3
1 2 10
2 1 3
2 1 5`}
  output={`6
16
25`}
  note="第二个操作把 a₂ 从 2 改成 12，所以前三项的和从 6 变成 16。"
/>

## 数据范围

对于全部数据，保证 $1 \le n, q \le 2 \times 10^5$，$|a_i| \le 10^9$，
$|v| \le 10^9$，$1 \le x \le n$，$1 \le l \le r \le n$。

| 子任务 | 分值 | 限制 |
| --- | --- | --- |
| 1 | 30 | $n, q \le 10^3$ |
| 2 | 30 | 没有 `1` 操作 |
| 3 | 40 | 无特殊限制 |

第二个子任务里序列不会变，预处理一遍前缀和就够了。

<Callout kind="tip" title="解题提示">

要同时支持单点修改与区间求和，树状数组是最省事的选择：它维护前缀和，单点加与
前缀查询都是 $O(\log n)$，区间和用 $\text{query}(r) - \text{query}(l-1)$ 得到。

关键是 `lowbit(x) = x & -x`，它取出 $x$ 二进制最低位的那个 1，决定了每个位置负责
的区间长度。

</Callout>

## 参考实现片段

```cpp title="fenwick.cpp" showLineNumbers
long long c[MAXN];

void add(int x, long long v) {
    for (; x <= n; x += x & -x) c[x] += v;
}

long long query(int x) {
    long long s = 0;
    for (; x > 0; x -= x & -x) s += c[x];
    return s;
}

// 区间和
cout << query(r) - query(l - 1) << '\n';
```

<Callout kind="warning">

树状数组的下标必须从 $1$ 开始，$0$ 会让 `x -= x & -x` 死循环。

序列和最大可达 $10^{14}$ 量级，数组与返回值都要用 64 位整数。

</Callout>
