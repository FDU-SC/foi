## 题目描述

**康威生命游戏**（规则见《生命游戏 · 第一百代》）。

一个**周期为 $k$ 的振荡器**，是指一个非空图案满足：

1. 演化 $k$ 代后**回到初始状态**
2. 演化 $1, 2, \dots, k-1$ 代都**不与初始状态相同**（最小周期恰好是 $k$）

每个场景给出**尺寸上限**与**周期 $k$**，请找出一个满足条件的图案提交。
**没有固定答案**——判题机（特判）会模拟验证你的图案，只要性质成立就得分。

## 提交格式

三个场景的图案**依次**贴在提交框里，**场景之间空一行**。每个图案用
`.`（死）和 `O`（活）表示，行列数不得超过对应场景的上限。

```
场景 1 的图案（若干行 . 和 O）

场景 2 的图案

场景 3 的图案
```

## 用模拟器找图案

下面的画板会**自动检测周期**：摆好图案，点「播放」，进入循环时它会停下并
报告「周期 N」——看到「周期 2 / 3 / 4」就可以复制提交了。

<GameOfLifeBoard defaultRows={16} defaultCols={16} maxRows={50} maxCols={50} />

<Callout kind="tip" title="已知线索">

- **k = 2**：三连格（`OOO`）——俗称十字星，最简单
- **k = 3**：pulsar——$13 \times 13$ 的经典图案，周期 3；它演化时会"呼吸"，
  提交时四周留几圈空白更稳妥（判题机也会自动扩展边界模拟）
- **k = 4**：留给勇敢的人。如果找到了，你可能是全队第一个发现它的人

</Callout>

<Callout kind="warning" title="判题规则">

- 图案**非空**，尺寸不超过场景上限
- 判题机在图案四周自动扩展空白后模拟 $k$ 代：第 $k$ 代必须回到初始，
  且第 $1..k-1$ 代都不能与初始相同
- 交一个 $k=2$ 的图案到 $k=4$ 的场景：第 2 代就重复了，判「最小周期是 2，不是 4」

</Callout>
