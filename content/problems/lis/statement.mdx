## 题目描述

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。

从中删去任意多个（也可以不删）元素，剩下的元素保持原来的先后顺序，就得到一个
**子序列**。请求出**严格递增**的子序列最长能有多长。

## 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

## 输出格式

一行一个整数，表示最长严格上升子序列的长度。

<Sample
  n={1}
  input={`7
3 1 2 1 8 5 6`}
  output={`4`}
  note="取 1、2、5、6 得到长度 4；没有更长的了。"
/>

<Sample
  n={2}
  input={`5
5 4 3 2 1`}
  output={`1`}
  note="序列严格递减，任取一个元素就是最长的上升子序列。"
/>

## 数据范围

对于全部数据，保证 $1 \le n \le 2 \times 10^5$，$|a_i| \le 10^9$。序列中可能有重复元素。

| 子任务 | 分值 | 限制 |
| --- | --- | --- |
| 1 | 30 | $n \le 10^3$ |
| 2 | 30 | $n \le 10^5$ |
| 3 | 40 | 无特殊限制 |

<Callout kind="tip" title="解题提示">

最直接的写法是设 $f_i$ 为「以 $a_i$ 结尾的最长上升子序列长度」，枚举前面所有比
$a_i$ 小的位置转移，复杂度 $O(n^2)$，足够拿到第一个子任务。

要过全部数据，换一个状态：维护数组 $t$，$t_k$ 表示「长度为 $k$ 的上升子序列，
结尾元素最小能是多少」。$t$ 一定是严格递增的，于是每读入一个数就在 $t$ 上二分，
把第一个不小于它的位置替换掉。最后 $t$ 的长度就是答案，复杂度 $O(n \log n)$。

</Callout>

## 参考实现片段

```cpp title="lis.cpp" showLineNumbers
vector<int> t;
for (int x : a) {
    auto it = lower_bound(t.begin(), t.end(), x);
    if (it == t.end()) t.push_back(x);
    else *it = x;
}
cout << t.size() << '\n';
```

<Callout kind="warning">

`t` 里存的是每种长度的最小结尾，**它本身不是一个合法的上升子序列**，只有长度有意义。

本题要求严格递增，所以二分用 `lower_bound`；如果改成允许相等，要换成 `upper_bound`。

</Callout>
